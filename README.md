# ✋ 손들고 말해요 — 우리 반 손들기 약속 보드

수업 시간에 손을 들지 않고 말한 횟수를 아이들이 눈으로 확인할 수 있는 교실용 보드입니다.
교실 TV·전자칠판에 띄워 두고 선생님이 학생 카드를 누르면 횟수가 올라갑니다.

## 사용법
- **학생 카드 누르기** → 1회 추가 (실수했으면 아래 알림의 `되돌리기` 또는 카드의 `−`)
- **약속 단계** → 기본값: 3회 🧹 교실 청소 / 5회 ✍️ 약속 글쓰기 (설정에서 자유롭게 변경·추가)
- 단계에 도달하면 카드 색이 바뀌고 할 일이 나타나요. 다 하면 체크 ✓
- **🛎️ 쉬는 시간 알림** → 시간표의 교시 끝 시간이 되면 종소리(딩동댕동)와 함께 ‘쉬는 시간 / 점심시간 / 오늘 수업 끝’ 화면과 다음 교시까지 남은 시간을 보여 줘요 (1분 뒤 저절로 닫힘)
- **🧴 후시딘** → 누르면 마우스가 연고 튜브로 바뀌고, 다친 친구 카드를 누르면 연고를 쭈욱 짜서 동글동글 바르고 큰 손이 ‘토닥! 토닥!’ 두 번 두드려요. 그때마다 뿅망치 맞은 횟수가 1번씩 줄고 흠집·못생긴 얼굴도 한 단계씩 나아요 (‘🩹 반창고 뗐다!’ 등). 0번이 되면 ‘다 나았다!’
- **💮 칭찬 도장** → 누르면 마우스가 ‘참 잘했어요’ 도장으로 바뀌고, 친구 카드를 누르면 꾹! 띠리링~ 소리와 함께 큰 칭찬 글씨·이름·‘💮 N번째’·반짝이가 터져요. 받은 횟수에 따라 카드가 100번까지 19단계로 변신해요 — 남자는 파랑·금빛 번개·방패·로켓·드래곤·‘우리 반 영웅’, 여자는 분홍 리본·하트·꽃·나비·유니콘·‘우리 반 프린세스’, 100번은 🏆 전설의 카드. `💮📋`에서 남녀(👦/👧) 정하기·횟수 보기·고치기 (손들기 횟수와 ⭐ 칭찬도장 탭과는 따로 세요)
- **📷 학생 사진** → ⚙️ 설정 → 📷 사진 넣기에서 사진 여러 장을 한꺼번에 넣으면 파일 이름의 학생 이름·번호로 저절로 짝지어지고, 남은 사진은 ‘사진 → 학생’ 순서로 눌러 짝지어요. 이름 옆에 동그란 얼굴 사진(오른쪽 아래 작은 표정), 발표 뽑기·칭찬·후시딘 화면에도 나와요. **사진은 그 컴퓨터 브라우저에만 저장되고 인터넷·저장소에는 올라가지 않아요** (백업 파일에는 함께 담겨요)
- **이름 옆 얼굴** → 모든 친구 이름 앞에 웃는 얼굴이 같은 줄로 나와요. 뿅망치를 맞을수록 😖 → 🥴 → 🤪 → 🤢 → 🐷 처럼 점점 못생겨지고, 맞은 횟수를 0으로 하면 다시 웃는 얼굴로 돌아와요
- **낡아지는 카드** → 뿅망치를 맞은 횟수에 따라 카드가 9단계로 점점 망가져요: 1번 금·기울어짐 → 3번 반창고·구김 → 5번 커피 얼룩 → 7번 찢어진 모서리·금 더 → 10번 테이프·곰팡이·접힌 귀퉁이 → 13번 거미줄·반창고 X → 16번 쩍 갈라짐·테이프 X → 20번 파리·냄새 → 25번 ‘🔧 수리 필요’ 도장 → 30번 불에 그을림 → 35번 낙서 → 40번 구멍 → 45번 물에 젖음·물방울 → 50번 신발 자국 → 60번 껌 → 70번 버섯 → 80번 쥐가 갉아먹은 가장자리 → 90번 출입 금지 테이프·파리 떼 → 100번 ‘폐기 처분’ 도장·💀·얼굴 덜덜 (모두 19단계). 단계가 오를수록 누렇고 칙칙해지고 더 기울어져요. 이름과 손들기 횟수는 늘 잘 보여요. 맞은 횟수를 0으로 하면 새 카드로 돌아와요
- **🔨 뿅망치** → 누르면 마우스가 뿅망치로 바뀌고, 친구 카드를 누르면 큰 ‘뿅!’ 망치 소리와 함께 화면 가득 큰 글씨·별 터짐·화면 흔들림, 빠르게 여러 번 누르면 ‘N연타!’, 맞은 친구 이름과 ‘🔨 N번째’가 크게 나오고 카드에 🔨N 표시, `🔨📋`에서 친구별 맞은 횟수 보기·고치기 (손들기 횟수는 올라가지 않아요 · 소리 끔이어도 망치 소리는 나요 · Esc로 끝내기)
- **🎤 발표 뽑기** → 발표할 친구를 무작위로 뽑아요. 한 번 뽑힌 친구는 모두 한 번씩 뽑힐 때까지 다시 안 나와요 (오늘 없는 친구는 빼 두기, 다시 넣기, 처음부터)
- **크게 보기** → 전체 화면, 교실 화면용
- **기록** → 누가 언제 몇 번 기록됐는지 / 지난 주 기록
- **✅ 체크 탭** → 학생별·날짜별 어긴 횟수, 할 일(청소·글쓰기) 완료/미완료, 밀린 할 일 모아 보기, 이름을 누르면 상세 기록, 엑셀(CSV) 저장
- **⭐ 칭찬도장 탭** → 한 주 동안 0회인 친구를 자동으로 골라 '참 잘했어요' 도장, 도장 개수(기본 3·5·8·10개)에 따라 보상, 보상 줬는지 체크
- **📆 달력 탭** → 월 달력에 일정 추가(여러 날·시간·종류·메모, 생일은 매년 반복), 일정 완료 체크, 날짜마다 '이날의 기록'(학급 일지), 다가오는 일정 D-day(보드 오른쪽에도 표시), 엑셀(CSV) 저장
- **🔄 초기화 탭** → 모두 0회로 새로 시작 / 매일·매주 자동 새로 시작 / 한 명만 0회 / 한 달 기록 지우기 / 기록 모두 지우기 / 도장판 새로 시작 / 완전 초기화

## 동료 선생님과 나누기 (USB · 인터넷 없이)
1. 이 저장소를 통째로 받거나(초록 `Code` → `Download ZIP`) 공유용 ZIP을 받아 압축을 풀어요.
2. `▶ 손들고 말해요 실행.bat` 더블클릭 → 엣지/크롬 창으로 열려요. (안 되면 `index.html`을 엣지·크롬으로 열기)
3. `⚙️ 설정`에서 반 이름·명단 입력, 🔊 소리 버튼 ✏️에서 내 목소리로 녹음할 수 있어요.
4. 자세한 내용은 `사용설명서.txt`를 보세요. `fonts` 폴더는 지우지 마세요 (인터넷 없이 글꼴을 보여 줘요).

## 저장 방식
기록은 사용하는 컴퓨터 브라우저(localStorage)에 저장됩니다. 서버로 전송되지 않습니다.
다른 컴퓨터로 옮길 땐 설정 → `파일로 내보내기` / `파일 불러오기`를 사용하세요.

## 배포 (GitHub Pages)
저장소 Settings → Pages → Branch: `main` / `(root)` → Save
