# ✋ 손들고 말해요 — 우리 반 손들기 약속 보드

수업 시간에 손을 들지 않고 말한 횟수를 아이들이 눈으로 확인할 수 있는 교실용 보드입니다.
교실 TV·전자칠판에 띄워 두고 선생님이 학생 카드를 누르면 횟수가 올라갑니다.

## 🕹️ 우리반 오락실 (arcade.html)
손들고 말해요와 따로 쓰는 **아이들용 오락실 앱**이에요. 주소: `https://kimgun124-boop.github.io/classroom/arcade.html`
- 아이들은 **반 번호를 누르고 비밀번호 4자리**로 들어와요 (비밀번호는 선생님이 정해서 쪽지로 나눠 줘요 · ⚙️ 선생님 → 🖨️ 비밀번호 쪽지 인쇄)
- 처음 들어오면 **캐릭터(이모지 얼굴)**를 골라요. 게임에서 내 얼굴로 나와요. 사진은 쓰지 않아요
- 게임 9개, 게임마다 **우리 반 랭킹전**
  - 🏆 점수전(혼자): 🐤 얼굴 날기 · 🚂 얼굴 기차 · 🔨 두더지 잡기 · 🧱 벽돌깨기 · 🏃 점프 달리기 · 🔢 2048
  - ⚔️ 승리전(둘이서): 🏐 얼굴 배구 · 🏒 얼굴 에어하키 · 🏓 얼굴 탁구 — **상대도 번호·비밀번호로 들어와서** 이기면 1승 (🤖 컴퓨터 연습은 랭킹에 안 들어가요)
  - 🌐 **다른 기기 친구와 대결**(☁️ Firebase 반만): 내 기기에서 친구 번호를 누르면 친구 태블릿·크롬북에 ‘⚔️ 대결 신청이 왔어요!’가 떠요. 친구가 **수락**을 누르면 두 기기가 직접 연결돼서 각자 자기 화면으로 해요 (신청한 친구 왼쪽 🟠, 수락한 친구 오른쪽 🔵). 이기면 1승, 끝나면 🔁 한 판 더
    - 두 기기는 **같은 와이파이**에 있어야 잘 돼요. 학교 와이파이가 기기끼리 연결을 막아 두었으면 연결되지 않을 수 있어요 (그럴 때는 🧒 이 기기에서 둘이 대결)
    - 신청 쪽지만 Firebase(`arcade/{반}/rooms`)에 잠깐 두었다가 연결되면 지워요. 게임 화면은 기기끼리 주고받아서 Firebase 사용량이 거의 늘지 않아요 (규칙은 그대로 써도 돼요)
- **🪙 코인 · 👕 아바타 상점**: 게임을 하면 코인을 모아요 (점수만큼 · 최고 기록 +10 · 친구 대결 승리 +25 / 패배 +5 · 하루 최대 400개). 코인으로 아바타 옷·모자·장신구·배경·테두리를 사고, 오락실에서만 파는 ✨ 움직이는 배경 12종 · 움직이는 테두리 8종 · 날개·오라 8종 · 반짝 효과 7종 · 펫 13종 · 칭호 9종도 있어요 (일반·희귀·영웅·전설 등급). 아바타가 로그인·홈·랭킹과 게임 속 얼굴로 나와요. **코인·산 아이템·입은 아바타는 학생별로 따로 저장돼서 앱을 고치거나 랭킹을 지워도 그대로 남아요.** 선생님은 ⚙️ → 🪙 코인에서 칭찬 코인을 줄 수 있어요
- 기록 저장: 💻 이 기기에만(교실 컴퓨터 한 대) 또는 ☁️ Firebase(아이들 각자 태블릿·크롬북, 반 전체 랭킹이 하나로). Firebase 연결 방법은 ⚙️ 선생님 → ☁️ 저장 탭에 있어요
- 얼굴 날기·기차·배구·에어하키는 `index.html`의 게임을 그대로 가져와 써요. index.html의 게임을 고친 뒤에는 `python3 arcade/build.py`를 실행하면 오락실(arcade.html)에도 반영돼요
- 🧑‍🏫 **선생님도 같이**: 로그인 화면 맨 끝 '선생님' 자리 → 선생님 비밀번호로 들어가 게임·랭킹·대결에 참여해요(선생님 화면 → 학생 탭에서 끌 수 있어요)
- 🖥️ 게임에 들어가면 **전체 화면**(주소창·탭 숨김)으로 꽉 차게 보여요. 홈으로 나오면 원래대로 돌아와요
- ⚡ **렉 줄이기**: 화면 크기에 맞춘 캔버스 해상도 상한, 이모지 얼굴 그림 기억(매 장면 다시 그리지 않음), 게임 중 뒤 화면 멈춤,
  친구 기록이 들어와도 게임 중엔 화면을 다시 그리지 않음, 기록 올리기를 '내 칸만 합쳐 쓰기'로 바꿔 22명이 동시에 올려도 서로 기다리지 않음,
  버벅이는 기기는 자동으로 반짝이(그림자 번짐)를 끄고 해상도를 낮춰요(그 기기에 기억)

## 사용법
- **학생 카드 누르기** → 1회 추가 (실수했으면 아래 알림의 `되돌리기` 또는 카드의 `−`)
- **약속 단계** → 기본값: 3회 🧹 교실 청소 / 5회 ✍️ 약속 글쓰기 (설정에서 자유롭게 변경·추가)
- 단계에 도달하면 카드 색이 바뀌고 할 일이 나타나요. 다 하면 체크 ✓
- **🛎️ 쉬는 시간 알림** → 시간표의 교시 끝 시간이 되면 종소리(딩동댕동)와 함께 ‘쉬는 시간 / 점심시간 / 오늘 수업 끝’ 화면과 다음 교시까지 남은 시간을 보여 줘요 (1분 뒤 저절로 닫힘)
- **💮 카드에서 바로 칭찬 도장** → 학생 카드 오른쪽 위(− 옆) 💮 버튼을 누르면 도장 찍기 없이 칭찬 도장이 1개씩 올라가요 (빼려면 💮📋 창의 −)
- **💮 칭찬 도장** → 누르면 마우스가 ‘참 잘했어요’ 도장으로 바뀌고, 친구 카드를 누르면 꾹! 띠리링~ 빰빠라밤 팡파르와 함께 이름 양쪽에 큰 천사 날개가 펼쳐져 파닥이고, 금빛 후광 빛줄기·왕관·불꽃놀이·화면 가득 꽃가루가 쏟아져요 (카드 얼굴에도 작은 날개). 남자는 하늘색·금빛, 여자는 분홍 날개. 받은 횟수(💮 칭찬 도장 + ⭐ 칭찬도장 탭 도장을 합친 수)에 따라 카드가 100번까지 19단계로 변신해요 — 남자는 파랑·금빛 번개·방패·로켓·드래곤·‘우리 반 영웅’, 여자는 분홍 리본·하트·꽃·나비·유니콘·‘우리 반 프린세스’, 20~79번은 색 테마 바탕(🍑복숭아 구름 20·🌙달빛 진주 30·🍃민트 숲 40·🌊푸른 바다 50·🔮보라 마법 60), 100번은 👑 레전드 카드(밤하늘 보석빛 바탕·황금 액자·빛나는 오라·금가루 — 한눈에 다른 급). `💮📋`에서 남녀(👦/👧) 정하기·횟수 보기·고치기 (손들기 횟수와 ⭐ 칭찬도장 탭과는 따로 세요)
- **😢 실망 도장** → 누르면 마우스가 파란 ‘실망이에요’ 도장으로 바뀌고, 약속을 안 지킨 친구 카드를 누르면 뿌우~ 뿌우~ 실망 소리와 함께 카드가 회색으로 털썩 처지고, 화면이 잠깐 어두워지며 먹구름·빗방울, 카드 장식(별·하트·리본·왕관…)이 우수수 떨어져요. 칭찬 도장이 1개 줄어서 카드 꾸미기가 그만큼 뒤로 돌아가고, 단계가 내려가면 ‘💔 왕관 잃었어요…’처럼 무엇을 잃었는지 알려 줘요 (손들기 횟수는 그대로 · Esc로 끝내기 · 잘못 찍었으면 `💮📋`에서 고쳐요)
- **📅 시간표 크게 보기** → 오른쪽 시간표를 누르거나 🔍를 누르면 화면 가득 크게 보여요 (지금·다음 교시 표시, 화면 누르거나 Esc로 닫기)
- **🎓 졸업식 D-day** → 위쪽에 졸업식까지 남은 ‘학교 오는 날’(주말·공휴일 빼고)이 D-숫자로 나와요. 눌러서 졸업식 날짜와 재량휴업일 같은 쉬는 날을 바꿀 수 있어요.
- **📋 구슬 뽑기 발표 순서** → ‘📋 발표 순서 (모두 도착)’으로 굴리면 모두 도착할 때까지 달리고, 도착 순서가 큰 목록으로 따로 나와요. ‘발표 끝! 다음 친구’(스페이스바)로 한 명씩 체크하고, 닫았다가 ‘지난 발표 순서 다시 보기’로 이어서 할 수 있어요.
- **🐤 얼굴 날기** → 혼자 하는 점수 도전 게임이에요. 친구 얼굴 새가 연필 사이를 날아가요(스페이스바·터치·클릭). 갈수록 빨라지고 틈이 좁아지며, 12점부터는 연필이 움직여요. 친구마다 최고 기록이 저장되고 ‘🏆 우리 반 랭킹’(최고 기록·오늘)으로 순위가 쌓여요.
- **🏒 얼굴 에어하키** → 친구 얼굴이 말렛이 되는 1대1 에어하키예요. 컴퓨터(쉬움·보통·어려움)나 친구와 둘이서 해요. 1P는 W·A·S·D와 F(대시), 2P는 방향키와 Enter(대시)로 움직이고, 전자칠판·터치 화면에서는 자기 쪽을 손가락으로 끌면 돼요. 능력치(스피드·대시·파워·몸집)는 얼굴 배구와 같아요.
- **🚂 얼굴 기차** → 혼자 하는 점수 도전 게임이에요. 내 얼굴 기관차를 방향키(W·A·S·D, 화면 밀기, 터치 화면은 방향 버튼)로 몰아서 기다리는 친구를 태우면 1점, 가끔 나오는 ⭐은 +3점! 태울수록 기차가 길어지고 빨라져요. ‘벽 통과(쉬움)’도 고를 수 있고, 친구별 최고 기록과 ‘🏆 우리 반 랭킹’(최고 기록·오늘)이 쌓여요.
- **🃏 얼굴 짝 맞추기** → 같은 친구 얼굴 카드 두 장을 찾는 기억력 게임이에요. 6~18쌍, ‘혼자·다 같이’ 또는 2팀·4모둠·6모둠 대결(짝을 찾으면 한 번 더, 틀리면 다음 모둠), 시작 전 미리 보기 3초·6초를 고를 수 있어요. 혼자 모드는 카드 수별 최고 기록(뒤집은 횟수·시간)이 저장돼요.
- **🔍 누구일까요?** → 친구 사진(없으면 아바타)이 모자이크·조각 열기·손전등·빙글 확대로 조금씩 보이면 누구인지 맞혀요. 💡 힌트(글자 수 → 초성 → 첫 글자), ✅ 정답 공개(Enter), ➡️ 다음 친구(→). 한 번 나온 친구는 모두 나올 때까지 다시 안 나와요. 🏆 모둠 점수판도 켤 수 있어요.
- **🪜 사다리타기** → 도구 줄 `🪜 사다리`. 탈 친구를 고르고(누르면 빼기/넣기), 아래 결과를 🎉 당첨 뽑기(당첨 인원·글자)·🔢 순서 정하기·👥 모둠 나누기·✏️ 직접 쓰기(청소 구역·1인 1역 등, 모자라면 ‘꽝’) 중에서 골라요. 결과는 ❓로 가려져 있다가, 친구 이름을 누르면 얼굴이 사다리를 따라 내려가며 색 선이 그려지고 결과가 열려요(스페이스바 = 다음 친구, ▶ 모두 타기). 📋 결과 보기에서 결과별로 누가 됐는지 모아 보여요
- **🔮 구슬 뽑기** → 친구 얼굴(사진이 없으면 색 구슬)이 동그란 구슬이 되어 못 밭·깔때기·바람개비·미끄럼틀·범퍼를 지나 굴러 내려가요. ‘먼저 도착한 친구’ 또는 ‘마지막에 도착한 친구’를 1명~여러 명 뽑고, 오늘 없는 친구는 빼고, ‘뽑힌 친구 빼고 다시’도 돼요. 오른쪽에 전체 길 지도와 도착 순서
- **👕 아바타 꾸미기** → 도구 줄 `👕 아바타`에서 친구마다 피부·머리 모양·머리색·눈·입·볼·모자/장식(왕관·리본·고양이 귀·토끼 귀·헤드폰·고글…)·안경·옷·옷 색·무늬를 골라 나만의 캐릭터를 만들어요. 학생 카드 얼굴 자리에 나오고(사진보다 먼저), 칭찬 도장을 많이 받으면 별 눈으로 저절로 바뀌어요. 🏞️ 배경 16가지(하늘·노을·밤하늘·바닷속·해변·숲·눈·사탕·하트·무지개·성·무대 조명·우주·은하수·칠판·황금빛)와 🖼️ 테두리 14가지(황금·무지개·네온·꽃·하트·별·얼음·불꽃·보석·나무·나뭇잎·번개·왕실)로 큰 사각형 액자를 꾸며요. `🎲 모두 만들기`로 반 전체를 한 번에 랜덤으로 만들 수 있어요. **💮 칭찬 도장을 모으면 특별 장비가 열려요**: 히어로 슈트·닌자복·기사 갑옷·무사 갑옷·우주복·황금 갑옷, 바이킹·기사·장군·우주·드래곤 투구, 나무칼·방패·강철 검·마법 지팡이·활·빛의 검·전설의 검과 방패 / 반짝 후드·교복 아이돌·트위드 재킷·시퀸 크롭·무대 드레스·다이아 드레스, 별 핀·하트 귀걸이·무대 마이크·진주 초커·반짝 스티커·나비 핀·티아라·크리스탈 왕관 (선생님은 ‘잠금 없이 입히기’로 미리 입혀 볼 수 있어요)
- **🧑‍🏫 선생님 아바타** → 마음 온도계의 👕(또는 👕 아바타 → 맨 위 ‘선생님’)에서 선생님 캐릭터를 꾸며요. 선생님 전용 옷(멋진 정장·카디건·실험 가운·체육복·턱시도·대마법사 로브·왕의 망토·선장·장군 제복), 모자(학사모·마법사 모자·선장 모자·황금 왕관·월계관·천사 링), 소품(지시봉·출석부·커피·호루라기·마법 지팡이·트로피·분필)과 모든 특별 장비를 잠금 없이 쓸 수 있어요. 온도계 단계에 따라 표정이 1단계 하트 뿅뿅 → 7단계 걱정·땀 → 8단계 💢 → 10단계 빨간 얼굴·김이 펄펄로 바뀌어요
- **📷 학생 사진** → ⚙️ 설정 → 📷 사진 넣기에서 사진 여러 장을 한꺼번에 넣으면 파일 이름의 학생 이름·번호로 저절로 짝지어지고, 남은 사진은 ‘사진 → 학생’ 순서로 눌러 짝지어요. 이름 옆에 동그란 얼굴 사진(오른쪽 아래 작은 표정), 발표 뽑기·칭찬 화면에도 나와요. **사진은 그 컴퓨터 브라우저에만 저장되고 인터넷·저장소에는 올라가지 않아요** (백업 파일에는 함께 담겨요)
- **이름 옆 얼굴** → 모든 친구 이름 앞에 웃는 얼굴이 같은 줄로 나와요.
- **🎤 발표 뽑기** → 발표할 친구를 무작위로 뽑아요. 한 번 뽑힌 친구는 모두 한 번씩 뽑힐 때까지 다시 안 나와요 (오늘 없는 친구는 빼 두기, 다시 넣기, 처음부터)
- **🎮 입장 / 아케이드 카드** → 학생 카드가 게임 대기방 슬롯처럼 바뀌었어요: 하늘색 스포트라이트 무대 위 얼굴(사진), 오른쪽 큰 횟수, 단계 색 이름판, 약속 잘 지키는 친구는 노란 ‘READY’ (두꺼운 테두리·아래 두께·사탕 광택·가끔 지나가는 반짝 빛, 물풍선 점, 흰 테두리 숫자, 누르면 쏙 들어가는 느낌). 화면을 열거나 `🎮 입장`을 누르면 ‘🎮 우리 반 입장!’ 글씨와 함께 카드가 하나씩 위에서 쿵! 떨어지며 먼지가 퐁 튀어요
- **🎨 테마** → 기본은 게임 대기방 같은 ‘아케이드 테마’: 진한 파란 기계 틀·위쪽 전광판·하늘색 테두리 패널·들어간 진한 칸·하늘색 사탕 버튼·주황 ‘준비’ 버튼·초록 디지털 시계, 학생 카드는 진한 슬롯 판 위에 놓이고 아래 상태 띠는 주황 글씨. 버튼을 누르면 원래 테마로 돌아가요
- **크게 보기** → 전체 화면, 교실 화면용
- **기록** → 누가 언제 몇 번 기록됐는지 / 지난 주 기록
- **✅ 체크 탭** → 학생별·날짜별 어긴 횟수, 할 일(청소·글쓰기) 완료/미완료, 밀린 할 일 모아 보기, 이름을 누르면 상세 기록, 엑셀(CSV) 저장
- **⭐ 칭찬도장 탭** → 한 주 동안 0회인 친구를 자동으로 골라 '참 잘했어요' 도장, 도장 개수(기본 3·5·8·10개)에 따라 보상, 보상 줬는지 체크
- **📝 자료 제출 탭** → 가정통신문 회신·동의서·과제처럼 걷을 자료를 추가(이름·마감 날짜·메모)하고, 친구 이름을 누르면 ‘냈어요 ✓’ 체크. ‘아직 안 낸 친구’가 위에 따로 모이고, 마감 뒤에 내면 ‘늦게’로 표시, D-day·마감 지남 표시, 모두 냄/모두 취소, 다 걷은 자료는 📦 보관. 아래 ‘한눈에 보기’ 표로 친구별 안 낸 개수, 엑셀(CSV) 저장. 마감이 된 자료 중 안 낸 건수가 탭에 빨간 숫자로 떠요
- **📆 달력 탭** → 월 달력에 일정 추가(여러 날·시간·종류·메모, 생일은 매년 반복), 일정 완료 체크, 날짜마다 '이날의 기록'(학급 일지), 다가오는 일정 D-day(보드 오른쪽에도 표시), 엑셀(CSV) 저장
- **🎁 마니또 탭** → 몰래 챙겨 줄 비밀 친구 뽑기. 한 줄로 이어지게 뽑아서 자기 자신·서로가 서로의 마니또가 되는 일이 없고, 지난 마니또와 같은 짝도 피해요(뺄 친구 고르기). 친구가 자기 이름을 누르고 🎁 상자를 열어 몰래 확인(20초 뒤 저절로 가려짐, 확인한 친구 ✅), 💌 미션 뽑기, 🎉 공개식(“○○를 몰래 챙겨 준 친구는?” → 두구두구 → 짠!), 🧑‍🏫 선생님 보기(전체 짝·다시 뽑기·미션 목록 고치기), 지난 마니또 기록
- **👥 학생 관리 탭** → 선생님만 보는 화면(들어갈 때마다 🔒 잠김). 친구별 생일·1인 1역·보호자·연락처·방과 후·특이사항, 상담·관찰·칭찬·생활지도·학부모 연락 기록(날짜별), 손들기·칭찬 도장·안 낸 자료·밀린 할 일 한눈에, 반 전체 기록 모아 보기, 명단·기록 엑셀(CSV) 저장. 이 컴퓨터에만 저장돼요
- **🔄 초기화 탭** → 모두 0회로 새로 시작 / 매일·매주 자동 새로 시작 / 한 명만 0회 / 한 달 기록 지우기 / 기록 모두 지우기 / 도장판 새로 시작 / 완전 초기화

## 동료 선생님과 나누기 (USB · 인터넷 없이)
1. 이 저장소를 통째로 받거나(초록 `Code` → `Download ZIP`) 공유용 ZIP을 받아 압축을 풀어요.
2. `▶ 손들고 말해요 실행.bat` 더블클릭 → 엣지/크롬 창으로 열려요. (안 되면 `index.html`을 엣지·크롬으로 열기)
3. `⚙️ 설정`에서 반 이름·명단 입력, 🔊 소리 버튼 ✏️에서 내 목소리로 녹음할 수 있어요.
4. 자세한 내용은 `사용설명서.txt`를 보세요. `fonts` 폴더는 지우지 마세요 (인터넷 없이 글꼴을 보여 줘요).

## 저장 방식
기록은 사용하는 컴퓨터 브라우저(localStorage)에 저장됩니다. 서버로 전송되지 않습니다.
다른 컴퓨터로 옮길 땐 설정 → `파일로 내보내기` / `파일 불러오기`를 사용하세요.
