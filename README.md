# ✋ 손들고 말해요 — 우리 반 손들기 약속 보드

수업 시간에 손을 들지 않고 말한 횟수를 아이들이 눈으로 확인할 수 있는 교실용 보드입니다.
교실 TV·전자칠판에 띄워 두고 선생님이 학생 카드를 누르면 횟수가 올라갑니다.

## 사용법
- **학생 카드 누르기** → 1회 추가 (실수했으면 아래 알림의 `되돌리기` 또는 카드의 `−`)
- **약속 단계** → 기본값: 3회 🧹 교실 청소 / 5회 ✍️ 약속 글쓰기 (설정에서 자유롭게 변경·추가)
- 단계에 도달하면 카드 색이 바뀌고 할 일이 나타나요. 다 하면 체크 ✓
- **🛎️ 쉬는 시간 알림** → 시간표의 교시 끝 시간이 되면 종소리(딩동댕동)와 함께 ‘쉬는 시간 / 점심시간 / 오늘 수업 끝’ 화면과 다음 교시까지 남은 시간을 보여 줘요 (1분 뒤 저절로 닫힘)
- **💮 카드에서 바로 칭찬 도장** → 학생 카드 오른쪽 위(− 옆) 💮 버튼을 누르면 도장 찍기 없이 칭찬 도장이 1개씩 올라가요 (빼려면 💮📋 창의 −)
- **💮 칭찬 도장** → 누르면 마우스가 ‘참 잘했어요’ 도장으로 바뀌고, 친구 카드를 누르면 꾹! 띠리링~ 빰빠라밤 팡파르와 함께 이름 양쪽에 큰 천사 날개가 펼쳐져 파닥이고, 금빛 후광 빛줄기·왕관·불꽃놀이·화면 가득 꽃가루가 쏟아져요 (카드 얼굴에도 작은 날개). 남자는 하늘색·금빛, 여자는 분홍 날개. 받은 횟수(💮 칭찬 도장 + ⭐ 칭찬도장 탭 도장을 합친 수)에 따라 카드가 100번까지 19단계로 변신해요 — 남자는 파랑·금빛 번개·방패·로켓·드래곤·‘우리 반 영웅’, 여자는 분홍 리본·하트·꽃·나비·유니콘·‘우리 반 프린세스’, 100번은 🏆 전설의 카드. `💮📋`에서 남녀(👦/👧) 정하기·횟수 보기·고치기 (손들기 횟수와 ⭐ 칭찬도장 탭과는 따로 세요)
- **😢 실망 도장** → 누르면 마우스가 파란 ‘실망이에요’ 도장으로 바뀌고, 약속을 안 지킨 친구 카드를 누르면 뿌우~ 뿌우~ 실망 소리와 함께 카드가 회색으로 털썩 처지고, 화면이 잠깐 어두워지며 먹구름·빗방울, 카드 장식(별·하트·리본·왕관…)이 우수수 떨어져요. 칭찬 도장이 1개 줄어서 카드 꾸미기가 그만큼 뒤로 돌아가고, 단계가 내려가면 ‘💔 왕관 잃었어요…’처럼 무엇을 잃었는지 알려 줘요 (손들기 횟수는 그대로 · Esc로 끝내기 · 잘못 찍었으면 `💮📋`에서 고쳐요)
- **📅 시간표 크게 보기** → 오른쪽 시간표를 누르거나 🔍를 누르면 화면 가득 크게 보여요 (지금·다음 교시 표시, 화면 누르거나 Esc로 닫기)
- **🔮 구슬 뽑기** → 친구 얼굴(사진이 없으면 색 구슬)이 동그란 구슬이 되어 못 밭·깔때기·바람개비·미끄럼틀·범퍼를 지나 굴러 내려가요. ‘먼저 도착한 친구’ 또는 ‘마지막에 도착한 친구’를 1명~여러 명 뽑고, 오늘 없는 친구는 빼고, ‘뽑힌 친구 빼고 다시’도 돼요. 오른쪽에 전체 길 지도와 도착 순서
- **👕 아바타 꾸미기** → 도구 줄 `👕 아바타`에서 친구마다 피부·머리 모양·머리색·눈·입·볼·모자/장식(왕관·리본·고양이 귀·토끼 귀·헤드폰·고글…)·안경·옷·옷 색·무늬를 골라 나만의 캐릭터를 만들어요. 학생 카드 얼굴 자리에 나오고(사진보다 먼저), 칭찬 도장을 많이 받으면 별 눈으로 저절로 바뀌어요. 🏞️ 배경 16가지(하늘·노을·밤하늘·바닷속·해변·숲·눈·사탕·하트·무지개·성·무대 조명·우주·은하수·칠판·황금빛)와 🖼️ 테두리 14가지(황금·무지개·네온·꽃·하트·별·얼음·불꽃·보석·나무·나뭇잎·번개·왕실)로 큰 사각형 액자를 꾸며요. `🎲 모두 만들기`로 반 전체를 한 번에 랜덤으로 만들 수 있어요. **💮 칭찬 도장을 모으면 특별 장비가 열려요**: 히어로 슈트·닌자복·기사 갑옷·무사 갑옷·우주복·황금 갑옷, 바이킹·기사·장군·우주·드래곤 투구, 나무칼·방패·강철 검·마법 지팡이·활·빛의 검·전설의 검과 방패 / 반짝 후드·교복 아이돌·트위드 재킷·시퀸 크롭·무대 드레스·다이아 드레스, 별 핀·하트 귀걸이·무대 마이크·진주 초커·반짝 스티커·나비 핀·티아라·크리스탈 왕관 (선생님은 ‘잠금 없이 입히기’로 미리 입혀 볼 수 있어요)
- **🧑‍🏫 선생님 아바타** → 마음 온도계의 👕(또는 👕 아바타 → 맨 위 ‘선생님’)에서 선생님 캐릭터를 꾸며요. 선생님 전용 옷(멋진 정장·카디건·실험 가운·체육복·턱시도·대마법사 로브·왕의 망토·선장·장군 제복), 모자(학사모·마법사 모자·선장 모자·황금 왕관·월계관·천사 링), 소품(지시봉·출석부·커피·호루라기·마법 지팡이·트로피·분필)과 모든 특별 장비를 잠금 없이 쓸 수 있어요. 온도계 단계에 따라 표정이 1단계 하트 뿅뿅 → 7단계 걱정·땀 → 8단계 💢 → 10단계 빨간 얼굴·김이 펄펄로 바뀌어요
- **📷 학생 사진** → ⚙️ 설정 → 📷 사진 넣기에서 사진 여러 장을 한꺼번에 넣으면 파일 이름의 학생 이름·번호로 저절로 짝지어지고, 남은 사진은 ‘사진 → 학생’ 순서로 눌러 짝지어요. 이름 옆에 동그란 얼굴 사진(오른쪽 아래 작은 표정), 발표 뽑기·칭찬 화면에도 나와요. **사진은 그 컴퓨터 브라우저에만 저장되고 인터넷·저장소에는 올라가지 않아요** (백업 파일에는 함께 담겨요)
- **이름 옆 얼굴** → 모든 친구 이름 앞에 웃는 얼굴이 같은 줄로 나와요.
- **🎤 발표 뽑기** → 발표할 친구를 무작위로 뽑아요. 한 번 뽑힌 친구는 모두 한 번씩 뽑힐 때까지 다시 안 나와요 (오늘 없는 친구는 빼 두기, 다시 넣기, 처음부터)
- **🎮 입장 / 아케이드 카드** → 학생 카드가 게임 대기방 슬롯처럼 바뀌었어요: 하늘색 스포트라이트 무대 위 얼굴(사진), 오른쪽 큰 횟수, 단계 색 이름판, 약속 잘 지키는 친구는 노란 ‘READY’ (두꺼운 테두리·아래 두께·사탕 광택·가끔 지나가는 반짝 빛, 물풍선 점, 흰 테두리 숫자, 누르면 쏙 들어가는 느낌). 화면을 열거나 `🎮 입장`을 누르면 ‘🎮 우리 반 입장!’ 글씨와 함께 카드가 하나씩 위에서 쿵! 떨어지며 먼지가 퐁 튀어요
- **🎨 테마** → 기본은 게임 대기방 같은 ‘아케이드 테마’: 진한 파란 기계 틀·위쪽 전광판·하늘색 테두리 패널·들어간 진한 칸·하늘색 사탕 버튼·주황 ‘준비’ 버튼·초록 디지털 시계, 학생 카드는 진한 슬롯 판 위에 놓이고 아래 상태 띠는 주황 글씨. 버튼을 누르면 원래 테마로 돌아가요
- **크게 보기** → 전체 화면, 교실 화면용
- **기록** → 누가 언제 몇 번 기록됐는지 / 지난 주 기록
- **✅ 체크 탭** → 학생별·날짜별 어긴 횟수, 할 일(청소·글쓰기) 완료/미완료, 밀린 할 일 모아 보기, 이름을 누르면 상세 기록, 엑셀(CSV) 저장
- **⭐ 칭찬도장 탭** → 한 주 동안 0회인 친구를 자동으로 골라 '참 잘했어요' 도장, 도장 개수(기본 3·5·8·10개)에 따라 보상, 보상 줬는지 체크
- **📆 달력 탭** → 월 달력에 일정 추가(여러 날·시간·종류·메모, 생일은 매년 반복), 일정 완료 체크, 날짜마다 '이날의 기록'(학급 일지), 다가오는 일정 D-day(보드 오른쪽에도 표시), 엑셀(CSV) 저장
- **🔄 초기화 탭** → 모두 0회로 새로 시작 / 매일·매주 자동 새로 시작 / 한 명만 0회 / 한 달 기록 지우기 / 기록 모두 지우기 / 도장판 새로 시작 / 완전 초기화

## 동료 선생님과 나누기 (USB · 인터넷 없이)
1. 이 저장소를 통째로 받거나(초록 `Code` → `Download ZIP`) 공유용 ZIP을 받아 압축을 풀어요.
2. `▶ 손들고 말해요 실행.bat` 더블클릭 → 엣지/크롬 창으로 열려요. (안 되면 `index.html`을 엣지·크롬으로 열기)
3. `⚙️ 설정`에서 반 이름·명단 입력, 🔊 소리 버튼 ✏️에서 내 목소리로 녹음할 수 있어요.
4. 자세한 내용은 `사용설명서.txt`를 보세요. `fonts` 폴더는 지우지 마세요 (인터넷 없이 글꼴을 보여 줘요).

## 저장 방식
기록은 사용하는 컴퓨터 브라우저(localStorage)에 저장됩니다. 서버로 전송되지 않습니다.
다른 컴퓨터로 옮길 땐 설정 → `파일로 내보내기` / `파일 불러오기`를 사용하세요.

## 배포 (GitHub Pages)
저장소 Settings → Pages → Branch: `main` / `(root)` → Save
