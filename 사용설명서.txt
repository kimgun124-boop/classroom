✋ 손들고 말해요 — 사용설명서
==================================================

수업 시간에 손을 들지 않고 말한 횟수를 아이들이 눈으로 확인하는 교실용 보드예요.
설치할 필요가 없고, 인터넷이 없어도 돼요.


■ 1. 실행하기
--------------------------------------------------
 0) 받은 zip 파일은 꼭 먼저 압축을 풀어 주세요!
    (zip 파일 오른쪽 클릭 → [압축 풀기] 또는 [모두 압축 풀기])
    zip 안에서 바로 누르면 실행되지 않아요.
 1) 압축을 푼 폴더를 통째로 USB나 바탕화면에 복사해요.
    (폴더 안의 파일이나 fonts 폴더를 지우거나 이름을 바꾸지 마세요)
 2) 「▶ 손들고 말해요 실행.bat」를 더블클릭해요.
    → 엣지(또는 크롬) 창이 주소창 없이 깔끔하게 열려요.

 ※ "Windows의 PC 보호" 또는 "게시자를 확인할 수 없습니다" 창이 뜨면
    [추가 정보] → [실행] 을 눌러 주세요. (인터넷에서 받은 파일이라 한 번 묻는 거예요)
 ※ 학교 컴퓨터에서 .bat 실행이 막혀 있거나 아무 반응이 없으면
    「손들고 말해요 열기 (bat이 안 될 때).html」 을 더블클릭하세요. (맥에서도 이걸로 열어요)
    또는 index.html 을 오른쪽 클릭 → [연결 프로그램] → Microsoft Edge 또는 Chrome 으로 열어도 똑같이 돼요.
 ※ 바탕화면에 바로가기를 만들어 두면 편해요.
    (실행.bat 오른쪽 클릭 → [보내기] → [바탕 화면에 바로 가기 만들기])


■ 2. 처음 한 번만 설정하기
--------------------------------------------------
 1) 오른쪽 위 [⚙️ 설정]
    - 반 이름 (예: 6학년 3반)
    - 학생 명단: 엑셀이나 나이스에서 이름만 복사해서 붙여넣기 하면 돼요
    - 약속 단계: 몇 번이면 무엇을 할지 (기본: 3회 교실 청소, 5회 약속 글쓰기)
    - 칭찬 보상
    - [저장하기]
 2) 오른쪽 [📅 오늘 시간표] 의 ✏️ → 요일별 과목과 교시 시간 적기
    (🪑 자리 알림은 이 시작 시간 30초 전에 울려요)
 3) [💬 선생님 말씀] 의 ✏️ → 아이들에게 하고 싶은 말


■ 3. 소리 버튼을 내 목소리로 바꾸기
--------------------------------------------------
 도구 줄의 🔊 소리 버튼 옆 ✏️ 를 누르면
  - 버튼 이름을 바꿀 수 있어요
  - [🎙️ 녹음] → 말하기 → [⏹️ 끝내기] 로 내 목소리로 바꿀 수 있어요 (최대 5초)
  - [↺ 처음 소리] 를 누르면 원래 소리로 돌아가요
 ※ 처음 녹음할 때 "마이크 사용을 허용할까요?" 가 뜨면 [허용] 을 눌러 주세요.
 ※ 1번 버튼 소리가 🪑 자리 알림(수업 30초 전)에 쓰여요.


■ 4. 매일 쓰기
--------------------------------------------------
 - 학생 카드를 누르면 1회 올라가요. 잘못 눌렀으면 아래 알림의 [되돌리기] 또는 카드의 [−]
 - 🏆 명예의 전당: 한 번도 안 눌린 친구가 올라가요. ✏️ 로 선생님이 직접 넣고 뺄 수 있어요
 - 🌡️ 선생님 마음 온도계: 1~10단계, 누르거나 ▲▼ 로 바꿔요
 - 🛎️ 쉬는 시간 알림: 시간표의 교시 끝 시간이 되면 종이 울리고 ‘쉬는 시간이에요!’ 화면이 떠요
   다음 교시까지 남은 시간이 보이고, 점심시간·마지막 교시 끝은 따로 알려 줘요 (버튼으로 켜고 끄기)
 - 🔨 뿅망치: 누르면 마우스가 뿅망치로 바뀌어요. 친구 카드를 누르면 큰 ‘뿅!’ 소리와 함께 화면 가득 글씨와 별이 터져요
   맞은 친구 이름과 ‘🔨 몇 번째’가 크게 나오고, 카드에도 🔨 맞은 횟수가 표시돼요
   [🔨📋] 버튼(뿅망치 중엔 위쪽 [📋 맞은 횟수])에서 친구별 횟수를 보고 − + 나 숫자로 고칠 수 있어요
   빠르게 여러 번 누르면 ‘뿅뿅뿅!!!’, ‘N연타!’ 로 더 세져요 (🔔 소리를 꺼 둬도 망치 소리는 나요)
   뿅망치로 누를 때는 횟수가 올라가지 않아요. 다 쓰면 [끝내기] 또는 Esc
 - 🎤 발표 뽑기: [🎲 뽑기] 또는 스페이스 바로 발표할 친구를 뽑아요
   한 번 뽑힌 친구는 모두 한 번씩 뽑힐 때까지 다시 안 나와요 (껐다 켜도 기억해요)
   오늘 없는 친구는 이름을 눌러 빼 두면 돼요 (다음 날 저절로 다시 들어와요)
 - 🖥️ 크게 보기: TV·전자칠판용 큰 화면
 - ⏳ 자동 줄이기: 켜면 1시간 동안 안 눌린 친구는 1개씩 줄어요 (기본은 꺼짐)
 - 🔄 초기화 탭: 매일·매주 자동으로 0회부터 새로 시작하게 할 수 있어요
 - 아침에 보드를 열면 화면을 아무 데나 한 번 눌러 두세요.
   (브라우저는 한 번도 누르지 않은 화면에서는 소리를 막아요)


■ 5. 저장과 옮기기 (중요)
--------------------------------------------------
 - 모든 기록은 "이 컴퓨터의 브라우저" 에 저장돼요. 인터넷으로 어디에도 보내지 않아요.
 - 같은 컴퓨터에서는 USB를 다른 칸에 꽂아도, 폴더를 옮겨도 기록이 그대로 있어요.
 - 다른 컴퓨터로 옮길 때: [⚙️ 설정] → [💾 파일로 내보내기] → 새 컴퓨터에서 [📂 파일 불러오기]
   (녹음한 목소리는 옮겨지지 않아요. 새 컴퓨터에서 다시 녹음해 주세요)
 - 브라우저의 "인터넷 사용 기록 삭제(쿠키 및 사이트 데이터)" 를 하면 기록이 지워져요.
   가끔 [💾 파일로 내보내기] 로 백업해 두세요.
 - 엣지와 크롬은 서로 기록을 따로 저장해요. 늘 같은 브라우저(실행.bat)로 여세요.


■ 6. 인터넷이 필요한 것
--------------------------------------------------
 - 온도계 10단계의 "유튜브 목소리" 만 인터넷이 필요해요. 나머지는 인터넷 없이 다 돼요.
